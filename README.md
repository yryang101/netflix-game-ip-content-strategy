# Netflix Game IP Content Strategy

## Project Overview
Netflix Top 10 데이터를 기반으로 장기 흥행 콘텐츠의 특성을 분석하고,
TMDB 메타데이터를 결합하여 게임 IP 기반 애니메이션 콘텐츠 전략을 제안하는 프로젝트입니다.

## Business Scenario
로스트아크 IP를 활용해 Netflix 오리지널 애니메이션 시리즈를 제작·출시한다면,
어떤 전략을 선택해야 장기 흥행 가능성을 높일 수 있을까?

## Key Question
게임 IP가 게임 안에서만 소비되지 않고,
다른 형태의 콘텐츠로 확장될 때 어떤 조건이 장기적인 관심을 만드는가?

## Data Sources
- Netflix Top 10
- TMDB API
